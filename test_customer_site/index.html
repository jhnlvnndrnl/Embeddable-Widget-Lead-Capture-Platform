This HTML page simulates an external customer website running on a different origin (e.g., http://localhost:5500 or file:///).

Cross-Origin Demonstration:
This page loads the widget script from the backend origin (http://localhost:8000/static/widget.js) and sends cross-origin AJAX form submissions to http://localhost:8000/submissions.

Embedded Widget Below:

The form below is dynamically injected by our single-line embed snippet:

<script src="http://localhost:8000/static/widget.js?id=demo-widget-newsletter" defer></script>
